# Data Model: Internal Authenticated Cloud E2E

The smoke does not introduce a shared database model. The following process records are held in
memory or emitted as sanitized evidence.

## AdminSession

| Field | Type | Rules |
|---|---|---|
| login | string | operator-provided, never printed |
| accessToken | string | in memory only, never logged or persisted |
| authorities | JWT claims | must include `CATALOG_ADMIN`, `INVENTORY_ADMIN`, `CAMPAIGN_ADMIN` |

## ShopperSession

| Field | Type | Rules |
|---|---|---|
| userId | UUID | returned by registration/login subject |
| accessToken | string | in memory only, never logged or persisted |
| generatedLogin | string | unique per run; may be printed only in sanitized form if needed |

## ProductFixture

| Field | Type | Rules |
|---|---|---|
| productId | UUID | created through Product admin API |
| variantId | UUID | generated by runner and supplied in composition |
| code/slug | string | unique run prefix |
| version | long | advanced by composition/publication ETags |
| sku | string | unique and used as Inventory SKU snapshot |

## InventoryFixtureCommand

| Field | Type | Rules |
|---|---|---|
| variantId | UUID | must match ProductFixture variant |
| skuSnapshot | string | nonblank, bounded; copied from Product SKU |
| quantity | positive long | default 1; enough for one reservation |
| reason | string | fixed non-secret smoke reason |

## CampaignFixture

| Field | Type | Rules |
|---|---|---|
| campaignId | UUID | created through Campaign admin API |
| version | long | read from ETag/body after each mutation |
| variantId | UUID | must match ProductFixture variant |
| requestedQuantity | positive long | equals Inventory quantity for the one-shot smoke |
| window | Instant pair | generated in UTC with bounded future start/end |

## ReservationEvidence

| Field | Type | Rules |
|---|---|---|
| purchaseRequestId | UUID | returned by 202 response and replay comparison |
| reservationId | UUID | returned by 202 response and owner query |
| campaignId/variantId | UUID | must match CampaignFixture/ProductFixture |
| idempotencyKey | string | raw value never printed; only a hash/label is reported |
| traceId | string | bounded trace identity, safe to report |

## OrderEvidence

| Field | Type | Rules |
|---|---|---|
| orderId | UUID | owner query result |
| purchaseRequestId | UUID | must equal ReservationEvidence |
| reservationId | UUID | must equal ReservationEvidence |
| campaignId/variantId | UUID | must equal fixtures |
| status | enum | expected initial `PENDING_PAYMENT` |
